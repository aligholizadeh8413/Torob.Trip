# ترب تریپ

دموی رابط کاربری ترب تریپ برای کشف، جست‌وجو، مقایسه و برنامه‌ریزی سفر. این نسخه فارسی و RTL است و مسیر اصلی جست‌وجوی پرواز تهران به مشهد را با داده‌های نمونه پیاده‌سازی می‌کند.

## اجرا

```bash
cd frontend
npm install
npm run dev
```

سایت در `http://localhost:3000` اجرا می‌شود. صفحه نتایج از مسیر `/search` و صفحه مقصدها از مسیر `/explore` در دسترس است.

داده‌های نتیجه در `frontend/src/lib/mockData.ts` قرار دارند و برای نمایش عملکرد پلتفرم برچسب‌گذاری شده‌اند. API سلامت Django در `/api/health/` تعریف شده است.
